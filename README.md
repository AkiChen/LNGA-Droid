# LNGA Droid

LNGA HarmonyOS 客户端的 Android 迁移工程，使用 Kotlin、Jetpack Compose 和 Material 3。

## 已实现

- 内嵌 NGA WebView 登录，自动捕获并验证登录会话
- 登录页使用 LNGA 兼容 UA，并提供 iframe 灰屏检测、错误提示、重试和外部浏览器诊断
- Android Keystore 加密保存 `ngaPassportUid` / `ngaPassportCid`
- NGA 多域名 GET 请求、Cookie/header、GB18030 解码、基础节流与失败轮换
- NGA 非标准 JSON 净化、Android 兼容的脚本包装 JSON 扫描器，以及帖子 JSON 截断时的 HTML 自动降级解析
- 主题列表支持按新回复、新发布排序，以及 24 小时/本周/本月热帖聚合；排序栏向下浏览时隐藏、反向滚动时浮动显示；支持分页和帖子详情 JSON 通道
- Kotlin BBCode AST 与 Compose 富文本：换行、粗斜体、下划线、删除线、颜色、引用、折叠、表格、代码块、列表、用户/楼层/主题链接、图片、大图预览和 238 个本地 NGA 表情
- NGA 分类版面图标宫格、版面搜索/选择、fid 直达，以及可排序的本地收藏版面；本地列表未收录的版面会自动使用 NGA 服务器搜索补全，收藏时持久化完整资料，取消收藏需要确认；长按版面可从 48 个图标中自定义或恢复自动/官方图标
- 主题列表、帖子详情和网页登录支持左右屏幕边缘滑动返回
- 主题列表自动追加下一页并使用右缘轻量进度滑块；帖子页浮动分页，中间页码支持吸附式滚轮选页，可选上拉/连续滑动翻页，双上滑间隔与距离阈值可调，翻页后自动回顶
- 主题标题颜色/粗斜体、锁定状态，并以可自定义小图标替代子版块文字标签
- 从 NGA `__U` 用户表回填楼层用户名和头像，并解码真正的匿名昵称
- 图片缩放与相册下载；同一回复的多张图片可在大图页左右滑动，长图使用顶部无界布局避免超高内容被居中裁切，并记录可复制的查看坐标诊断；视频控制栏自动隐藏及横屏全屏播放
- Bilibili/b23.tv、微博、小红书及抖音短链/直链摘要卡片（点击交由对应 App 或浏览器打开，不在应用内播放）
- NGA ZIP/RAR 等帖子附件以独立卡片展示，下载前校验登录态、响应类型及 RAR 文件头，并保存到系统 `Downloads/LNGA`
- 主题回复可自动识别结构化 Markdown，支持标题、引用、列表、代码块、强调与链接，并对 NGA BBCode 内容保持原渲染链路
- 可复制正文，以及点击正文外区域即可清除当前文字选择
- 浏览历史、版面收藏排序、主题色和浏览过滤设置
- 外观可选跟随系统、浅色、深色或极致黑夜；自动夜间模式默认开启，每天 23:00 至次日 07:00 切换为 OLED 纯黑主题
- 主题列表已读标记，以及按 UID 保存页面/楼层的可选自动续读
- 独立设置页、App 字体缩放、始终/手动/仅 Wi-Fi 图片加载策略，以及媒体与网页缓存统计和清理
- 通用内置网页浏览器开关；平台媒体卡片链接继续交由对应 App 或外部浏览器
- NGA 旧图床自动迁移，并识别 HTTP 200/404 的 43 字节 CDN 占位响应；近期附件执行一次有限缓存旁路重试
- AI 服务配置中心：OpenAI、Model Gate、DeepSeek、智谱 GLM、豆包、MiniMax、Kimi 与自定义 OpenAI-compatible 服务
- AI API Key 使用独立 Android Keystore AES-GCM 密钥加密保存，支持掩码状态、替换和单独删除
- AI 配置支持安全复制：沿用服务地址、能力和经 Keystore 重新加密的 API Key，只需修改模型或配置名称
- AI 模型列表读取、手工模型名、启用配置及低成本连接测试，并提供认证、限流、模型、超时等中文错误
- AI 配置表单会明确显示缺失项；新建配置不再因空闲状态误判为“忙碌”而禁用保存
- 独立 AI 对话页：多轮流式输出、停止生成、重新生成、新建/删除会话及本地历史；每个会话可单独切换并记住所用模型；底部使用悬浮胶囊输入区，键盘打开时消息区和输入栏一起避让
- AI 对话仅使用已配置服务的普通 Chat Completions；实验性联网搜索入口已移除，后续可接入独立搜索插件
- AI 上下文限制为最近 24 条、约 4 万字，并在请求时显示实际发送范围；单条输入最多 12000 字
- AI 增量 Markdown 支持标题、分隔线、中英文列表、引用、代码块、粗斜体、删除线、行内代码与链接
- 主题 AI 总结支持当前页或明确确认后的整个主题，显示收集/整理/裁剪进度，可取消并进入 AI 对话继续追问
- AI 总结和用户分析可在离开原页面后继续运行；顶栏使用单个圆弧四芒星，空闲按明暗主题显示灰色、处理中在星形内部流动彩色渐变、完成后显示金色
- AI 结果统一进入完整会话页面；摘要准备阶段显示独立进度，返回原页面不会终止后台任务，也不会短暂显示上一次会话
- 摘要会话按主题 `tid`、用户分析按 `uid` 本地绑定；当前页面始终打开对应结果，重新生成会替换该对象之前的会话
- 点击非匿名楼层用户可查看公开资料、主题/回复样本、活跃版面与发帖时段；确认发送范围后可进行带局限声明的 AI 用户成分分析
- 从回复列表进入用户资料页时保存精确滚动位置，返回后恢复同一楼层和像素偏移，不覆盖原浏览进度
- 用户公开资料与活动记录独立加载；活动请求遇到 502/503/504 会有限退避重试，分页失败时保留已成功数据，并提供手动重试与脱敏网络诊断
- 已成功生成用户光谱的头像显示小型金色 AI 标记；用户页直接展示最近一次成功分析，重新生成期间保留旧结果，成功后再替换
- 主题页顶栏长标题以缓慢跑马灯展示完整内容
- AI 会话标题同样使用慢速跑马灯；新建与删除收进标题长按菜单，模型切换和历史会话保留为独立入口
- 主题列表以当前版面图标替代返回箭头；回复列表不占用左侧图标空间，返回继续支持系统返回与双侧边缘手势
- 主题列表的回复数字按热度着色：5 条以下为灰色，5～60 条连续加深，60 条及以上使用主题错误红色
- 主题标题长按菜单提供复制完整标题和收藏/取消收藏，标题本身不再进入文字选择；长图查看器上下各保留四分之一屏黑色缓冲区
- 首页退出登录需要二次确认，且明确保留本地收藏、浏览历史和设置
- 深色模式与 Material 3 基础 UI；极致黑夜使用纯黑背景，媒体内容不主动调暗

## 当前限制

- 已支持网页登录及开发者凭据导入，尚未实现原生 RSA + 验证码登录
- BBCode 仍未覆盖 NGA 的全部私有节点，未识别的表情会保留原始 token
- 已实现主题本地收藏和帖子附件下载；尚未实现发帖、NGA 账号云端收藏、私信与通知
- 用户光谱只统计当前登录态可见的有限公开记录，不等同于 NGA 完整历史；AI 输出属于模型推断
- 尚未使用真实账号和真机完成端到端验证

后续改进项及验收标准见 [`docs/BACKLOG.md`](docs/BACKLOG.md)；AI 与系统体验迁移路线见
[`docs/AI_SYSTEM_MIGRATION_PLAN.md`](docs/AI_SYSTEM_MIGRATION_PLAN.md)。

## 构建

```bash
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'
./gradlew :core:parser:test :app:assembleDebug :app:lintDebug
```
