# LNGA Android 改进项

## NET-001：用户活动临时错误恢复

- 状态：已在 0.22.1 实现，待 OPPO 真机与真实 NGA 服务验收
- 影响范围：用户资料页、用户公开主题/回复样本、用户光谱

### 已实施方案

1. 502、503、504 响应执行有限的分域名退避重试，并在耗尽后显示明确中文提示。
2. 用户基础资料与活动记录使用独立加载状态；活动失败不再清空已经显示的资料。
3. 主题和回复分别加载，单页失败时保留此前成功页以及另一类成功记录。
4. 部分样本生成 AI 用户分析前明确提示范围不完整。
5. 错误卡片提供“重试活动记录”和“复制诊断”；诊断只包含用途、页码、域名、状态码、耗时、重试次数及网络类型，不包含 Cookie、UID、CID 或完整查询参数。

### 验收标准

- 用户资料成功、活动接口返回 503 时，资料卡继续显示且可以手动重试。
- 某类活动第二页失败时，第一页与另一类成功记录继续显示，并标注样本不完整。
- 临时错误恢复后无需退出用户页面即可显示完整统计。
- VPN 开启/关闭两种情况下，复制的报告足以区分请求阶段和网络路径，且不含登录凭据。

## IMG-001：NGA 旧图床迁移与 CDN 负缓存恢复

- 状态：已在 0.14.0 实现，待真机复验
- 记录日期：2026-08-25
- 影响范围：帖子内图片、图片探测、原图下载

### 已确认根因

1. `img.nga.178.com` 是不可正常访问的旧图床域名。直连时 DNS 无法解析；经 VPN/代理时表现为 HTTPS 握手中断或 HTTP 502。允许明文 HTTP、重试旧域名都不能解决。
2. 同一旧附件路径改用 `https://img.nga.cn` 可以返回真实图片，因此旧图床地址应迁移到当前图片域名，而不是回退旧域名 HTTP。
3. `img.nga.cn` 可能在部分 VPN/CDN 节点短暂返回 `404 + image/gif + 43 字节`占位图；同一请求绕过代理可返回真实 JPEG。已通过缓存旁路请求命中源文件，确认属于 CDN 负缓存或节点同步延迟，不是 Coil 解码、Cookie、防盗链或 Android HTTP 策略问题。

### 已实施方案

1. 将已确认废弃的 NGA 图片域名规范化到 `https://img.nga.cn`，保留路径、查询参数和片段。
2. 图片展示、探测、下载共用同一套域名规范化逻辑。
3. 将 `404 + image/gif + 43 字节`识别为 NGA/CDN 占位响应，不直接判定图片永久失效。
4. 对占位响应进行有限的延迟重试；仅对近期附件尝试一次缓存旁路参数，避免老旧失效图片造成重复请求。
5. 诊断信息补充 `eo-cache-status`、`age`、`x-request-id`、实际请求域名、是否执行域名迁移及缓存旁路。
6. 若规范化域名仍返回稳定 404，则按真实失效处理并保留“重试/下载/复制诊断”交互。

### 验收标准

- 旧地址 `http://img.nga.178.com/attachments/mon_201209/14/-47218_5052bc4cc6331.png` 能通过规范化后的地址展示、放大和下载。
- 新上传图片首次命中 43 字节 CDN 占位图时能够有限重试，缓存恢复后无需重新进入主题即可显示。
- 真实失效图片不会无限重试，也不会把 43 字节占位 GIF 当作帖子图片展示。
- 日志能够区分旧域名失效、CDN 占位负缓存、真实 404、网络错误和解码错误。
